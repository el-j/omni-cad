What you get

Everything you need for code-driven CAD

OmniCAD is built for developers who want to author 3D models in code — with a professional workflow, AI integration, and full VS Code comfort.

🔀

Universal Engine Router

Drop any CAD file in your workspace. OmniCAD reads the extension, picks the right backend (OpenGeometry, FreeCAD, or OpenSCAD), and compiles — no configuration needed.

🎮

Live 3D Viewer

A Three.js-powered WebGL panel opens beside your editor. Every save triggers an instant re-compile and mesh update, with orbit controls, wireframe toggle, and grid overlay.

📤

Multi-format Export

One click to export your model to STEP, STL, IGES, or glTF — the four most widely used formats in mechanical CAD and 3D printing.

🤖

MCP / AI Integration

The built-in Model Context Protocol server exposes compile_and_measure and export_geometry tools. Any MCP-capable AI agent can drive OmniCAD programmatically.

🔒

Secure Webview

Strict Content Security Policy with per-session nonces. No inline scripts, no remote resources, no data exfiltration — your models stay local.

🚀

Professional CI/CD

Automated semantic versioning, E2E tests in a headless VS Code instance, coverage reports on every PR, and a signed .vsix attached to every GitHub release.

CAD Engines

Pick your language, OmniCAD does the rest

Each engine is a thin adapter that implements a common interface — compile, getBrepMetadata, export, dispose — making it trivial to add new backends.

⚡
OpenGeometry
.ts .js

Parametric geometry via WebAssembly. Write your model in TypeScript or JavaScript — no external install needed. Ideal for generative design and web-friendly workflows.

// my-model.ts const radius = 10; const height = 20; // Your OpenGeometry API calls…
🏗️
FreeCAD
.py .fcmacro

Full BREP solid modelling via the FreeCAD Python API. Access Part, PartDesign, Draft, and all FreeCAD workbenches from plain Python scripts — with STEP and IGES export.

import FreeCAD, Part doc = FreeCAD.newDocument() box = doc.addObject("Part::Box", "Box") box.Length = 20 doc.recompute()
📐
OpenSCAD
.scad

CSG-based solid modelling. The lingua franca of 3D-printable parametric models. Uses the openscad CLI to render STL meshes for preview and export.

difference() { cube([20, 20, 20], center = true); sphere(r = 12, $fn = 64); }
Under the hood

Clean, extensible architecture

OmniCAD uses the Strategy pattern: the EngineRouter dispatches to the correct adapter at runtime based on file extension. Adding a new engine is a matter of implementing four methods.

Optional prerequisites

OpenGeometry works out of the box (WebAssembly — no install needed).  ·  FreeCAD requires FreeCADCmd on your PATH (or set omniCAD.freecadPath).  ·  OpenSCAD requires openscad on your PATH (or set omniCAD.openscadPath).
